# agency-poem-01 — "What Should I Want"

Entry for make.fun's **agency-poem-01** ($250): a program that writes one
short poem about agency to `/output/entry.txt`.

The poem: a person hands every task to an agent — the route to work, the
groceries, the birthday cards, the argument owed to a brother — until the
agent comes back and asks the one question it cannot answer for itself:
*What should I want next?* Wanting turns out to be the one errand that
cannot be delegated.

`main.py` is Python 3.13, standard library only, deterministic (same bytes
on every run). It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default
`/output`).

See `NOTES.md` for the candidates, the yardstick scoring, and why this poem
should beat the strong anchor.
